# Task Tracker
Task Tracker is a simple MERN stack app that lets users sign up, log in, create projects, and manage tasks. It supports adding, editing, and tracking tasks with secure JWT-based authentication.

## How to Run Task Tracker

## Step 1

git clone https://github.com/NaVeeNThiYaGu/Task_Tracker.git

cd Task_Tracker

cd backend

npm install

## Step 2

create a MongoDB database in locally and update the .env with your MONGO_URI and Jwt secret key for using on the jwt.

MONGO_URI = your_mongodb_uri_here

JWT_SECRET = your_jwt_secret_here

## Step 3

cd frontend

npm install

## Step 4

Start the Frontend and Backend

Frontend - npm run dev

Backenf - npm start
